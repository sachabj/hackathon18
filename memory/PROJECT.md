# PROJECT — Le "Waze des bons plans étudiants"

> Nom de l'app : _à définir_

## Pitch
Une app / site web communautaire où **tout le monde peut voir et signaler des bons plans étudiants**,
comme Waze pour les incidents routiers : les utilisateurs publient, les autres confirment ou signalent qu'un plan n'est plus valable.

## Cible
Étudiants (en priorité ENSAI / Rennes pour la démo, extensible partout).

## Catégories
- 🍔 **Restaurants** — ex : offre étudiante McDo
- 🛒 **Magasins** — ex : réduction pâtes Intermarché
- 🚆 **Transport** — sous-catégories :
  - Train
  - Avion
  - Bus
  - Covoiturage

## Fonctionnalités envisagées
### MVP (indispensable pour la démo de samedi 13h)
- [ ] Consulter la liste / carte des bons plans
- [ ] Filtrer par catégorie (et sous-catégorie transport)
- [ ] Publier un bon plan (titre, description, catégorie, lieu, date d'expiration optionnelle)
- [ ] Voter / confirmer un bon plan ("toujours valable" 👍 / "expiré" 👎) — l'esprit Waze

### Bonus (si le temps le permet)
- [ ] Carte interactive avec géolocalisation
- [ ] Comptes utilisateurs + points / réputation
- [ ] Recherche texte, tri par popularité / proximité / récence
- [ ] Expiration automatique des plans trop downvotés
